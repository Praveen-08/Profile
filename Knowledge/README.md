# Knowledge Base

Persistent context for PK Visuals / Listing Launch / QuickReel, structured per the Phase 2
"Build Your Knowledge Base" plan — so AI tools (Claude, ChatGPT, Cursor) don't have to be
re-briefed on the business every session.

- `Brand/` — PK Visuals identity: positioning, packages, pricing, visual/tone rules.
- `Real Estate/` — the craft: photography, video, drone, twilight, agent reels.
- `Business/` — go-to-market: pricing strategy, marketing, sales, SEO, ads, social.
- `Software/` — the product side: Listing Launch, QuickReel, roadmap, data model, screens.

Everything here is grounded in what actually exists in this repo (`pkvisuals/`,
`listing-launch-os/`, `quickreel/`, `hdr-photo-editor/`) as of 2026-07-13, with open
questions flagged explicitly rather than invented. Update these files as real decisions get
made — a knowledge base that goes stale is worse than no knowledge base.

See `Software/Roadmap.md` for the full master plan and an honest status check against it.
