# Mission

Working statement, drawn from the site's own positioning (`index.html` hero + meta description) —
refine with Praveen's actual words if these don't match:

> Give Auckland real estate agents visuals — photography, video, drone, floor plans, reels — that
> help them win listings, attract buyers, and sell faster, delivered fast (24hr photo / 48hr
> video) and to a consistent premium standard.

## Company-building mission (from the master roadmap)
Beyond the day-to-day shoot business: build PK Visuals as the proving ground for an AI-first
media workflow, then package that workflow as software (Listing Launch, QuickReel) that other
real estate photographers and agents can subscribe to. Every internal tool is evaluated against:
"could another photographer pay $29–99/month for this?" See `Software/Roadmap.md`.
