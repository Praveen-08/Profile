# Vision

3-stage arc (see `Software/Roadmap.md` for the full detail):

1. **PK Visuals** — a real, cash-generating Auckland real estate media business, run with
   AI-assisted operations end to end (booking, editing, delivery, marketing).
2. **Internal software becomes product** — the tools built to run PK Visuals (Listing Launch OS,
   HDR photo editor, QuickReel AI video engine) mature into standalone SaaS products other
   photographers and agents pay for.
3. **Platform** — Listing Launch + QuickReel + AI marketing tooling become a connected operating
   system for real estate media businesses, with international reach beyond Auckland/NZ.

Long-term picture: not "a photographer with some scripts," but a media company that productises
its own operations as software.
