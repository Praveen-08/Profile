# Pricing

## What's published
`index.html` schema.org `LocalBusiness` markup declares:
```
"priceRange": "$350–$1,300+"
```
No package-level NZD prices are published on the site — every package CTA is "Enquire" (send
property address + campaign details, get availability + a quote back).
